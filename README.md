## 🎯 How I Think About Frontend

1. **Type safety is foundational.** Branded types prevent entire classes of bugs. Discriminated unions catch missing cases at compile time.

2. **Data layer isolation.** Swappable API modules mean you're not locked into implementation details.

3. **Accessibility by default.** ARIA labels, keyboard navigation, screen reader support aren't afterthoughts—they're part of the design system.

4. **Performance is UX.** Custom SVG rendering over chart library bloat. Intersection Observer over useEffect + useState races.

5. **Honest tradeoffs.** Real products balance pragmatism with idealism. Document the tradeoffs openly.
